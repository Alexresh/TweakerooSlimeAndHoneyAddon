# TweakerooSlimeAndHoneyAddon

**Аддон для [Tweakeroo]([https://www.curseforge.com/minecraft/mc-mods/tweakeroo](https://modrinth.com/mod/tweakeroo)), изменяющий поведение слайм-блоков и медовых блоков в Minecraft.**

## Описание

Этот мод расширяет функциональность Tweakeroo, добавляя новую опцию конфигурации `SlimeAndHoneyBehavior`. Когда эта опция включена, моды заменяют физические свойства слайм-блоков и медовых блоков на свойства камня, позволяя перемещаться по ним без замедления и эффектов отскока.

## Функциональность

### При включенной опции:
- **Слайм-блоки** теряют отскок и вязкость
- **Медовые блоки** теряют эффект замедления и невозможности прыгать
- Оба блока ведут себя как обычные каменные блоки по трению, скорости передвижения, высоте прыжка и отскоку

### При выключенной опции:
- Все блоки возвращаются к оригинальным физическим свойствам


## Использование

1. Запустите Minecraft с Fabric
2. Откройте меню конфигурации Tweakeroo (по умолчанию `X + C`)
3. Найдите раздел `Yeets` и там будет `SlimeAndHoneyBehavior` вместо `DISABLE_SLIME_BLOCK_SLOWDOWN`
4. Включите опцию для активации мода

## Конфигурация

Мод автоматически заменяет следующие параметры блоков при включении:

### Слайм-блок:
- Трение (Friction) → как у камня
- Скорость передвижения (Speed Factor) → как у камня
- Отскок (Bounce Restitution) → как у камня

### Медовый блок:
- Трение (Friction) → как у камня
- Скорость передвижения (Speed Factor) → как у камня
- Отскок (Bounce Restitution) → как у камня
- Высота прыжка (Jump Factor) → как у камня
